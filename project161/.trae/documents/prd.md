## 1. 产品概述

木本植物和古树名木普查记录工具是一款面向林业部门、文物保护机构和科研人员的在线管理系统，用于对古树名木进行专业化档案管理、健康状况评估、普查工作追踪和数据统计分析。旨在实现古树名木信息的数字化、标准化和可视化管理，提升古树保护工作的科学性和效率。

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 系统管理员 | 管理员分配 | 全部功能权限，用户管理，系统配置 |
| 普查员 | 管理员分配 | 古树档案录入、健康评估填写、多媒体上传 |

| 领导/决策者 | 管理员分配 | 数据分析查看、统计报表、进度总览 |

### 2.2 功能模块

1. **首页仪表盘**：关键数据概览、待办事项、最新动态、快捷入口
2. **古树档案模块**：古树专业档案、历史文化记载、多媒体存档
3. **健康状况评估模块**：健康状况定期评估、生长环境评估、保护处理措施记录
4. **普查工作管理模块**：网格化管理、进度追踪、数据质量审核
5. **数据分析模块**：树种分布统计分析、树龄分布分析、区域密度热力图

## 3. 核心流程

1. **古树建档流程**：普查员在责任区域发现古树 → 录入专业档案信息 → 上传多媒体资料 → 填写历史文化记载 → 提交审核
2. **健康评估流程**：定期评估提醒 → 普查员现场评估 → 填写健康状况和生长环境 → 记录保护处理措施 → 生成评估报告
3. **数据审核流程**：普查员提交数据 → 审核员审核坐标精度/照片质量/数据完整性 → 通过或退回修改 → 审核完成
4. **普查管理流程**：管理员划分网格 → 分配责任区域 → 普查员执行调查 → 系统追踪进度 → 全部完成后生成统计报告

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深森林绿 (#1B4332) + 暖琥珀色 (#D4A373) 作为点缀，体现自然与历史的厚重感
- **辅助色**：象牙白 (#FEFAE0) 背景，深棕 (#5C4033) 文字，浅苔绿 (#95D5B2) 用于状态指示
- **按钮风格**：圆角矩形（8px），森林绿填充 + 白色文字，悬停时加深
- **字体**：标题使用 Noto Serif SC（宋体风格体现文化底蕴），正文使用 Noto Sans SC
- **布局风格**：左侧固定导航栏 + 右侧内容区，卡片式布局，大量留白
- **图标风格**：使用 lucide-react 线性图标，保持简洁自然
- **视觉元素**：叶片纹理点缀、年轮样式装饰、渐变绿色过渡

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 首页仪表盘 | 数据总览 | 四宫格统计卡片（森林绿渐变底色 + 白色数字 + 图标），带微动画计数器 |
| 首页仪表盘 | 待办事项 | 左对齐列表，左侧色条标识紧急程度，右侧操作按钮 |
| 古树档案列表 | 搜索筛选 | 顶部搜索栏 + 可展开筛选面板，下拉选择器 + 范围滑块 |
| 古树档案列表 | 档案卡片 | 3列网格卡片，上方照片 + 下方文字信息，悬停提升阴影 |
| 古树档案详情 | 专业档案 | 左侧照片墙 + 右侧信息表，分区块展示各维度数据 |
| 古树档案详情 | 历史文化记载 | 时间线布局，卡片式历史事件展示 |
| 古树档案详情 | 多媒体存档 | 标签式分类（全株/树干/叶片/果实），网格图库 + 灯箱查看 |
| 健康评估详情 | 现状描述 | 雷达图综合评分 + 各指标详细说明卡片 |
| 普查网格管理 | 网格地图 | 全屏地图视图 + 右侧面板显示区域详情和分配信息 |
| 普查进度追踪 | 进度地图 | 地图上已调查区域绿色覆盖，待调查区域灰色，底部进度条 |
| 数据分析 | 树种分布 | 环形图 + 排名列表，颜色编码各树种 |
| 数据分析 | 树龄分布 | 柱状图 + 折线趋势，X轴为树龄区间 |
| 数据分析 | 区域密度 | 热力图 + 侧边排名卡片 |

### 4.3 响应式设计

- 桌面优先设计（1440px 基准）
- 平板适配（768px-1024px）：导航栏折叠为汉堡菜单，卡片从3列变2列
- 移动端适配（<768px）：单列布局，底部标签导航，表单全屏展示
- 触摸优化：按钮最小44px触摸区域，滑动手势支持
