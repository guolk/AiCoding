## 1. 产品概述

「博物志」—— 一款在线博物馆与遗址旅游追踪工具，帮助文化旅行爱好者系统化记录每次参观体验、追踪特别展览、沉淀历史知识、管理愿望清单，并以数据可视化呈现个人的文化探索轨迹。

- 目标用户：热爱博物馆与文化遗产旅行的群体，希望在参观过程中记录、回顾和规划文化之旅
- 核心价值：将零散的参观经历转化为结构化的个人文化档案，让每一次博物馆之旅都留下深度印记

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 个人用户 | 本地使用，无需注册 | 使用全部功能，数据存储于本地 |

### 2.2 功能模块

1. **首页**：个人文化探索概览、快速导航、最近参观记录、统计数据摘要
2. **参观记录页**：已参观博物馆/遗址档案列表、新增/编辑参观记录
3. **参观详情页**：单次参观的完整档案（评分、照片、速写、笔记）
4. **展览追踪页**：特别展览记录、展览图录与纪念品、展览亮点笔记
5. **学习笔记页**：历史知识记录、理解变化追踪、延伸阅读管理
6. **愿望清单页**：想去的博物馆清单、旅行规划中的博物馆、特展提醒
7. **统计数据页**：参观总览、国家覆盖、类型偏好、时间趋势

## 3. 核心流程

用户打开应用后，从首页概览个人文化探索全貌。通过侧边导航在各模块间切换：
- **记录参观**：首页点击"新增参观" → 填写基本信息 → 添加评分和推荐理由 → 上传照片/速写 → 保存
- **追踪展览**：进入展览追踪页 → 点击新增展览 → 填写展览信息 → 添加图录/纪念品 → 记录亮点笔记
- **学习沉淀**：参观后进入学习笔记页 → 新增知识记录 → 记录理解变化 → 添加延伸阅读
- **规划旅行**：进入愿望清单页 → 添加想去的博物馆 → 设置优先级 → 规划旅行 → 添加特展提醒
- **回顾统计**：进入统计数据页 → 查看各项数据可视化 → 了解个人文化探索轨迹

## 4. 用户界面设计

### 4.1 设计风格

- **设计理念**：「古典雅韵」—— 融合博物馆的庄重气质与现代极简美学，营造沉静的文化氛围
- **主色调**：深墨色（#1a1a2e）为背景基底，搭配古铜金（#c9a96e）作为强调色，象牙白（#f5f0e8）作为文字和卡片底色
- **辅助色**：暗绛红（#8b4513）用于标记和重点，灰蓝（#6b7b8d）用于次要信息
- **字体**：标题使用衬线体（Noto Serif SC），正文使用无衬线体（Noto Sans SC），营造文雅对比
- **按钮风格**：圆角矩形，古铜金描边，悬停时填充金色渐变
- **布局**：左侧固定导航栏 + 右侧内容区，卡片式内容展示
- **图标**：使用 Lucide 图标库，线条风格

### 4.3 响应式设计

- 桌面优先设计，最小宽度 1024px 为主要适配目标
- 导航栏在桌面端为侧边固定栏，移动端折叠为底部标签栏
- 卡片网格自适应列数（4→2→1列）
- 表单在移动端全屏展示
