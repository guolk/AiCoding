# 会员管理系统 PRD（产品需求文档）

## 1. Product Overview

会员管理系统是一个为健身馆、培训机构、场馆等机构设计的完整会员管理工具，涵盖会员档案管理、会员卡管理、签到管理、营销管理和经营数据分析五大核心模块。

- **主要目标**：帮助机构高效管理会员信息、追踪消费行为、提升会员活跃度、优化经营决策
- **目标用户**：场馆前台、销售顾问、店长/经营者
- **市场价值**：一站式解决机构会员管理的核心痛点，提升运营效率和客户服务质量

## 2. Core Features

### 2.1 User Roles

| Role | Registration Method | Core Permissions |
|------|---------------------|------------------|
| 管理员 | 系统内置 | 全部功能权限，包括数据配置、系统设置 |
| 前台 | 管理员创建 | 会员管理、签到、会员卡操作 |
| 销售 | 管理员创建 | 会员录入、查看数据报表 |

### 2.2 Feature Module

1. **会员档案模块**：会员基本信息录入、照片存档、特殊需求/备注记录
2. **会员卡管理模块**：卡型配置、有效期/次数追踪、暂停/延期/升级/退卡记录
3. **签到管理模块**：签到记录、活跃度分析、到期预警名单
4. **营销管理模块**：生日提醒、续费提醒、活动通知记录
5. **经营数据模块**：活跃/流失统计、卡型分布、签到高峰时段分析

### 2.3 Page Details

| Page Name | Module Name | Feature description |
|-----------|-------------|---------------------|
| 首页仪表盘 | 总览 | 关键指标展示、快速操作入口、今日提醒 |
| 会员列表 | 会员档案 | 会员列表展示、搜索筛选、新增/编辑会员 |
| 会员详情 | 会员档案 | 会员完整信息、照片、特殊需求、历史记录 |
| 卡型配置 | 会员卡管理 | 卡型创建/编辑、规则设置（月卡/季卡/年卡/次卡/储值卡） |
| 会员卡列表 | 会员卡管理 | 卡片状态追踪、操作记录 |
| 签到记录 | 签到管理 | 签到历史、消耗记录、签到方式统计 |

## 3. Core Process

### 3.1 新会员入会流程
1. 前台登录系统 → 进入会员列表页面
2. 点击"新增会员" → 录入会员基本信息
3. 上传会员照片 → 记录特殊需求和备注
4. 选择卡型 → 完成购卡/充值
5. 系统生成会员卡 → 会员档案建立完成

### 3.2 会员卡消费流程
1. 会员到店 → 前台查询会员信息
2. 识别会员照片确认身份 → 执行签到操作
3. 系统自动扣除次数/更新有效期
4. 生成签到记录 → 更新会员活跃度

### 3.3 营销提醒流程
1. 系统每日自动扫描会员数据
2. 识别生日会员 → 生成生日祝福提醒
3. 识别即将到期会员（N天前）→ 生成续费提醒名单
4. 前台查看提醒列表 → 执行跟进操作

## 4. User Interface Design

### 4.1 Design Style

#### 配色方案
- **主色调**：深蓝 #1e3a5f（专业、稳重、信任感）
- **辅助色**：青色 #0ea5e9（活力、科技感）
- **成功色**：绿色 #10b981（健康、成长）
- **警告色**：橙色 #f59e0b（注意、提醒）
- **危险色**：红色 #ef4444（过期、警告）
- **中性色**：灰白渐变 #f8fafc → #e2e8f0（背景层次）

#### 设计风格
- **整体风格**：现代商务简约风格，专业但不沉闷
- **布局**：左侧固定导航 + 顶部状态栏 + 主内容区（卡片式布局）
- **卡片设计**：圆角 12px，微妙阴影，悬浮效果
- **按钮样式**：圆角 8px，渐变背景，悬浮动画
- **字体**：标题使用 Playfair Display（优雅感），正文使用 Source Sans 3（清晰易读）

#### 视觉细节
- **背景**：浅色渐变背景，带细微网格纹理
- **图标**：Lucide 图标，统一线性风格
- **动画**：平滑过渡（0.3s ease），卡片悬浮微动效，页面加载渐显
- **数据可视化**：使用 Recharts 组件库，柔和配色，清晰标注

### 4.2 Page Design Overview

| Page Name | Module Name | UI Elements |
|-----------|-------------|-------------|
| 首页仪表盘 | 总览 | 统计卡片（4个大卡片）、今日提醒列表、快速操作按钮、图表预览区 |
| 会员列表 | 会员档案 | 搜索栏、筛选器、数据表格（带照片缩略图）、分页、新增按钮 |
| 会员详情 | 会员档案 | 左侧头像/基本信息卡片、右侧 Tabs（基本信息、会员卡、签到记录、备注） |
| 卡型配置 | 会员卡管理 | 卡型卡片列表（网格布局）、新增卡型表单弹窗、规则配置面板 |
| 会员卡列表 | 会员卡管理 | 状态标签筛选、会员卡卡片（显示余额/次数/有效期）、操作按钮 |
| 签到记录 | 签到管理 | 日期范围选择器、签到方式筛选、数据表格、统计摘要 |
| 经营报表 | 经营数据 | 标签页切换（活跃/流失、卡型分布、高峰时段）、图表区域、数据表格 |

### 4.3 Responsiveness

- **桌面端**：左侧导航展开（240px），主内容区自适应
- **平板端**：左侧导航收起（64px图标栏），主内容区优化布局
- **移动端**：底部导航栏，卡片式垂直布局，简化表格

## 5. Non-functional Requirements

- **性能**：页面首屏加载 < 2s，数据查询 < 500ms
- **数据存储**：本地 localStorage 持久化存储，支持数据导入导出
- **安全性**：模拟登录验证，关键操作二次确认
