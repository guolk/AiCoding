## 1. 产品概述

声景收藏馆(SoundScape Archive)是一款专业的自然声音收藏与录音管理工具，为自然录音师、声景爱好者和生态研究者提供一站式的录音档案管理、地理标注、声音分析和收藏展示解决方案。

- 解决的核心问题：自然录音资源分散、缺乏系统化管理、无法进行深度声学分析和地理可视化
- 目标用户：自然录音师、声景生态学家、户外爱好者、自然教育工作者
- 产品价值：构建个人声景数字博物馆，通过多维度分析挖掘自然声音的科学与艺术价值

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 录音师用户 | 本地账户/无需注册(本地应用) | 完整的录音管理、分析、展示功能 |

### 2.2 功能模块

1. **录音档案模块**：录音信息录入、分类标签管理、质量评估系统
2. **地理标注模块**：Leaflet地图标注、GPS坐标管理、时间对比分析、热力图可视化
3. **声音分析模块**：音频参数显示、频谱图生成、时域分析、物种活跃时段统计
4. **收藏展示模块**：播放列表管理、声音旅行地图、录音故事编辑、精选集展示

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 首页仪表板 | 数据概览 | 录音统计卡片、最近添加、快捷操作入口、声景日历 |
| 录音档案页 | 录音列表 | 录音卡片网格、筛选排序、搜索、批量操作 |
| 录音详情页 | 档案管理 | 完整信息表单、分类标签、质量评分、文件管理 |
| 地图中心页 | 地理标注 | Leaflet交互式地图、GPS标记、录音点弹窗、图层切换 |
| 热力图页面 | 声景分析 | 声音丰富度热力图、季节对比、时间轴播放 |
| 声音分析页 | 音频分析 | 波形可视化、频谱图、参数面板、时间分布图表 |
| 收藏展示页 | 播放列表 | 精选集管理、主题分类、播放控制、故事卡片 |
| 声音旅行页 | 地图故事 | 声音旅行路线、时间线、地点故事图文 |

## 4. 用户界面设计

### 4.1 设计风格

**设计主题**：自然有机(Natural Organic) + 数据可视化驱动

- **主色调**：深森林绿 `#1a4d2e` - 代表自然与生命
- **辅助色**：大地棕 `#8b7355`、天蓝色 `#87ceeb`、暖橙色 `#e8a87c`
- **背景色**：米白色 `#faf8f5` 搭配深灰绿 `#2c3e35` 暗色模式
- **按钮风格**：圆角矩形、微渐变背景、悬浮时轻微放大+阴影加深
- **字体**：标题使用 'Cormorant Garamond' 衬线字体（优雅自然感），正文使用 'Sora' 无衬线字体（现代易读）
- **布局风格**：卡片式布局配合不对称留白，大量使用自然纹理背景和微妙的噪点质感
- **图标风格**：手绘线条风格图标，配合自然元素(树叶、水滴、声波、山脉)

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 首页仪表板 | 数据概览 | 玻璃拟态统计卡片、环形进度图、时间线录音日历、悬浮动画 |
| 录音档案页 | 列表浏览 | 瀑布流卡片布局、标签筛选栏、搜索框、悬停时显示波形预览 |
| 录音详情页 | 档案表单 | 分栏布局（左：音频播放器+波形；右：信息表单+标签） |
| 地图中心页 | 地图交互 | 全屏Leaflet地图、自定义标记点(声纹图标)、侧栏信息面板 |
| 热力图页面 | 数据可视化 | 渐变色彩热力图层、时间轴滑块、季节切换按钮、数据统计 |
| 声音分析页 | 频谱分析 | 大型Canvas频谱图、时域波形图、参数仪表盘、时间分布柱状图 |
| 收藏展示页 | 播放列表 | 封面卡片轮播、音频播放器条、故事文字排版、淡入动画 |
| 声音旅行页 | 地图故事 | 地图路线动画、时间线节点、图文卡片、滚动触发动画 |

### 4.3 响应式设计

- **桌面优先**：1440px以上为基准设计，采用多栏布局
- **平板适配**：1024px时折叠为双栏，侧边栏变为抽屉式
- **手机适配**：768px以下转为单列布局，底部导航栏替代顶部菜单
- **触控优化**：所有交互元素最小尺寸44x44px，支持滑动操作

### 4.4 动效设计

- **页面加载**：元素错落淡入（staggered fade-in），首屏使用视差背景
- **地图交互**：标记点弹跳出现，热力图渐变色层过渡动画
- **音频播放**：波形实时跳动，频谱图动态渲染，播放按钮呼吸灯效果
- **卡片悬停**：轻微上浮+阴影扩散，背景图片缓慢放大
- **滚动效果**：时间线节点随滚动点亮，故事内容逐段显现
